# VB-013 – PSM/Admin ohne Bottom-Tab-Bar auf Mobile

- **Schweregrad:** Medium
- **Priorität:** P2
- **Kategorie:** Mobile First
- **Rollen:** Psychosoziale Mitarbeit, Einrichtungs-Admin
- **Fundort:** `app/templates/partials/tabbar.html` (deckt nur
  Teilnehmer/Berufstrainer ab)

## Problem

CLAUDE.md §24 fordert "Mobile First" für die gesamte Anwendung. Die
Bottom-Tab-Bar existiert aber nur für Teilnehmer und Berufstrainer – PSM und
Admin sind auf Mobile nur über ein Hamburger-Menü erreichbar, ein spürbarer
Bedienungsbruch zwischen den Rollen.

## Lösungsvorschlag

`tabbar.html` um rollenspezifische Einträge für PSM (z. B. "Freigaben",
"Konto") und Admin (z. B. "Benutzer", "Abteilungen", "Konto") erweitern,
analog zum bestehenden Muster für Teilnehmer/Berufstrainer.

## Aufwand

**S** – Template-Erweiterung, kein Backend-Eingriff.

## Abhängigkeiten

Keine.

## Abnahmekriterien

- [ ] PSM und Admin sehen auf schmalen Screens eine konsistente
      Bottom-Tab-Bar mit den für sie relevanten Bereichen
