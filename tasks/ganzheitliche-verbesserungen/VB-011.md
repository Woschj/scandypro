# VB-011 – Keine Verzahnung Kanban ↔ Wochenbericht (Doppel-Erfassung)

- **Schweregrad:** Medium
- **Priorität:** P2
- **Kategorie:** Prozess-Effizienz / Kognitive Entlastung
- **Rollen:** Teilnehmer
- **Fundort:** `app/routers/wochenberichte.py` (`bericht_erstellen`),
  `app/routers/kanban.py`

## Problem

Erledigte Kanban-Karten (mit `abgeschlossen_am` in der jeweiligen
Kalenderwoche) enthalten oft dieselbe Information, die für den
Wochenbericht erneut per Freitext getippt werden muss. Für eine Zielgruppe,
für die "wenig Aufwand"/"kognitive Entlastung" explizites Leitprinzip ist
(CLAUDE.md §24), ist doppelte Dateneingabe unnötige Reibung.

## Lösungsvorschlag

Beim Öffnen des Wochenbericht-Formulars optional eine Liste der in der
jeweiligen Woche abgeschlossenen Kanban-Karten (Titel) als Vorschläge
anzeigen, die sich per Klick in das jeweilige Tagesfeld übernehmen lassen
(kein Zwang, keine automatische Übernahme).

## Aufwand

**M** – Query über `KartenBewegung`/`abgeschlossen_am` pro Woche, kleines
JS/Alpine-Snippet zum Übernehmen in Tagesfelder.

## Abhängigkeiten

Keine.

## Abnahmekriterien

- [ ] Wochenbericht-Formular zeigt optionale Vorschläge aus abgeschlossenen
      Kanban-Karten derselben Woche
- [ ] Übernahme ist rein optional, überschreibt nichts automatisch
