# VB-015 – Demo-Logins hart codiert unabhängig von `SEED_DEMO_DATA`

- **Schweregrad:** Low
- **Priorität:** P3
- **Kategorie:** Sicherheit / Konfiguration
- **Rollen:** alle
- **Fundort:** `app/templates/auth/login.html:18`

## Problem

Die Demo-Zugangsdaten (inkl. Klartext-Passwort `demo1234`) werden auf der
Login-Seite unabhängig davon angezeigt, ob `SEED_DEMO_DATA=true` gesetzt
ist. In einer echten Einrichtung ohne Demo-Daten wären das nutzlose,
potenziell irreführende Klartext-Zugangsdaten auf der öffentlichen
Login-Seite (auch wenn die Accounts dort nicht existieren).

## Lösungsvorschlag

Anzeige an das `SEED_DEMO_DATA`-Flag koppeln (Server-seitig, per
Template-Kontextvariable aus `app/core/config.py`).

## Aufwand

**XS** – ein bedingter Block im Template + eine Kontextvariable.

## Abhängigkeiten

Keine.

## Abnahmekriterien

- [ ] Demo-Zugangsdaten erscheinen auf der Login-Seite nur, wenn
      `SEED_DEMO_DATA=true`
