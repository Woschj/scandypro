# UI-022 – "Kein Zugriff"-Seiten sind Sackgassen ohne Handlungsvorschlag

- **Schweregrad:** Low
- **Priorität:** P3 – Nice to have
- **Kategorie:** Micro-UX / Error Recovery
- **Fundort:** [app/templates/bewerbungen/kein_zugriff.html](app/templates/bewerbungen/kein_zugriff.html),
  [app/templates/wochenberichte/kein_zugriff.html](app/templates/wochenberichte/kein_zugriff.html),
  [app/templates/wohlbefinden/kein_zugriff.html](app/templates/wohlbefinden/kein_zugriff.html),
  [app/templates/freigaben/kein_zugriff.html](app/templates/freigaben/kein_zugriff.html)

## Problem

Alle vier rollenbasierten "Kein Zugriff"-Seiten bestehen ausschließlich
aus einer Überschrift und einem erklärenden Absatz. Es gibt keinen
Rücksprung-Link (z. B. "Zurück zum Dashboard"), keinen Hinweis auf eine
für die aktuelle Rolle passende Alternative – die Nutzer:in muss
selbstständig über die Topnav einen neuen Weg finden.

## Warum das ein Problem ist

- Kleine, aber wiederkehrende Reibung: vier separate Sackgassen-Seiten,
  die alle denselben fehlenden Baustein teilen (Recovery-Pfad).
- Wirkt im Vergleich zu den sonst sehr durchdachten Leer-Zuständen der
  App (die z. B. im Dashboard aktiv erklären, warum etwas nicht sichtbar
  ist, und wie man es ändert) unfertig.

## Erwartete Nutzerauswirkung

Kleiner, aber spürbarer Verbesserung im Umgang mit einem Zugriffsfehler –
Nutzer:innen finden ohne Umweg über die Navigation zurück zu einer
sinnvollen Seite.

## Lösungsvorschlag

Auf allen vier Seiten einen konsistenten Rücksprung-Link ergänzen, z. B.
`<p><a href="/">← Zurück zum Dashboard</a></p>`, wie er in anderen
Detail-Ansichten der App bereits als Standardmuster existiert (z. B.
`<p><a href="/kanban">&larr; Alle Boards</a></p>` in `kanban/board.html`).

## Aufwand

**XS** – eine Zeile pro Template.

## Abhängigkeiten

Keine.

## Abnahmekriterien

- [ ] Alle vier "Kein Zugriff"-Seiten enthalten einen funktionierenden
      Rücksprung-Link zum Dashboard
- [ ] Visuelles Muster konsistent mit bestehenden "← Zurück"-Links im
      Rest der Anwendung
