# UI-018 – Widersprüchlicher Copy-Text zur Bewerbungs-Freigabe

- **Schweregrad:** Medium
- **Priorität:** P2
- **Kategorie:** Content / Micro-UX
- **Fundort:**
  - [app/templates/bewerbungen/kein_zugriff.html:5-7](app/templates/bewerbungen/kein_zugriff.html):
    "Ein Freigabe-System für Berufstrainer:innen ist für eine spätere
    Phase geplant und in diesem Prototyp noch nicht enthalten."
  - Widerspricht: [app/templates/bewerbungen/uebersicht.html:202-259](app/templates/bewerbungen/uebersicht.html)
    (vollständiges "Für wen freigeben"-UI mit Umfang-Auswahl, Ablaufdatum,

## Problem

Der Text auf der "Kein Zugriff"-Seite für Bewerbungen behauptet, ein
Freigabe-System für Berufstrainer:innen existiere noch nicht – tatsächlich
ist genau dieses Feature bereits vollständig implementiert (granulare
Freigabe pro Bewerbung/gesamt, Ablaufdatum, Widerruf, dedizierte
Trainer-Ansicht). Der Text ist damit vermutlich aus einer früheren
Entwicklungsphase stehengeblieben.

## Warum das ein Problem ist

- Falsche Information direkt im Produkt untergräbt Vertrauen, sobald ein
  Berufstrainer diese Seite in einem Zustand ohne aktive Freigabe sieht
  (z. B. bevor irgendein Teilnehmer freigegeben hat) und daraus fälschlich
  schließt, das Feature existiere grundsätzlich nicht.
- Widerspricht CLAUDE.md Abschnitt 24 ("Transparenz") – veraltete Aussagen
  über Systemfähigkeiten sind das Gegenteil von Transparenz.

## Erwartete Nutzerauswirkung

Korrekte Erwartungshaltung bei Berufstrainer:innen, die (noch) keine
freigegebenen Bewerbungsdaten sehen.

## Lösungsvorschlag

Text ersetzen durch eine Formulierung, die den tatsächlichen Zustand
beschreibt, z. B.: "Bewerbungsdaten sind nur sichtbar, wenn die
jeweilige Teilnehmer:in aktiv freigegeben hat. Aktuell liegt für dich
keine Freigabe vor." – konsistent mit der bereits vorhandenen Formulierung
auf dem Berufstrainer-Dashboard ("Nur sichtbar, wenn die Teilnehmer:in
aktiv freigegeben hat").

## Aufwand

**XS** – Textänderung in einer Zeile.

## Abhängigkeiten

Keine.

## Abnahmekriterien

- [ ] Text auf `bewerbungen/kein_zugriff.html` beschreibt den
      tatsächlichen Freigabe-Mechanismus korrekt
- [ ] Konsistente Formulierung mit `dashboard.html` und
      `bewerbungen/uebersicht.html`
